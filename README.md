# Jarvis AI Assistant

Jarvis est un assistant IA personnel simple développé en React.  
Cette application web permet de poser des questions en commençant par "Jarvis" et d'obtenir des réponses basiques.

## Fonctionnalités

- Interface de chat simple et intuitive
- Réponses automatiques basiques (heure, date, état)
- Compatible PC et mobile via navigateur
